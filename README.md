# 医院挂号预约服务

## 需要用到的数据结构

- 队列
- 链表
- 数组
- 堆

## 实现要求

- 线上预约模块（名额分配:20）
- 线上预约到现场签到后进入排队
- 线下预约排队模块（名额分配:20）
- 复诊排队
- 预约信息详情显示
- 科室显示匹配对应患者

### 想法

- 菜单进行功能分类和选择
- 数组来存放对应科室的头节点
- 数组存放线上预约信息存储，签到后放入队列
- 队列实现预约信息的储存
- 堆排序实现复诊信息储存
- 合并队列形成挂号排队信息面板
- 结构体来做科室信息以及制作患者预约名片
- 链表来进行各个科室的排队显示
- 最后考虑要不要储存信息
